# React Tic-Tac-Toe Game

A classic Tic-Tac-Toe game built with React, featuring a responsive design for play on various screen sizes.

## Features

- Classic Tic-Tac-Toe gameplay (X vs. O).
- Responsive design (works well on desktop and mobile).
- Win detection.
- Draw detection.
- Restart game functionality.
- Simple and intuitive user interface.

## Technologies Used

- React
- CSS (or your preferred styling solution)
